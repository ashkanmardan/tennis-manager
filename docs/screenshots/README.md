# Screenshot capture checklist

The committed images are real screenshots captured from the v1.0.1 Android app on 2026-09-20: home dashboard, finance, session form, sessions, and reports. No image editing was used. Two supplied profile screenshots were excluded because they visibly contain phone and card numbers. These images document UI coverage; they do not establish broad device compatibility. Record the app version and Android device used for future captures, and never include real names, phone numbers, card numbers, or payment details.
