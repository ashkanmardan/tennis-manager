# Tennis Manager v1.0.1

## Highlights

This is the first verified public Android release prepared from the merged `main` commit.

## Fixes

- Completing onboarding now returns through the app's existing state routing.
- Player details, the first package, and generated sessions are saved atomically.
- A failed save shows a retry message and does not leave partial setup records.

## Technical notes

- Package: `com.ashkan.tennis_manager`
- Version: `1.0.1` (version code `2`)
- Minimum Android API: 24
- Target and compile API: 36
- APK: `TennisManager-v1.0.1.apk`
- Source commit: `ff160e7decb7eb3bcddb4ba12eac4188b3d4443b`

## Known limitations

The app is Persian-first and currently stores data locally. Backup and restore, upgrade behavior, and permissions need broader device coverage in future testing. The nested `lib/lib` duplicate tree remains under audit.

## Installation

Download the APK from this GitHub Release, keep the previous installation in place when upgrading, and verify the checksum in `SHA256SUMS.txt`.

## Privacy

Use synthetic data while evaluating the app. JSON backups can contain personal and payment information and can be sent to another app through Android sharing. See [privacy details](../PRIVACY.md).

## Checksums

The SHA-256 checksum is published beside the APK in `SHA256SUMS.txt`.
