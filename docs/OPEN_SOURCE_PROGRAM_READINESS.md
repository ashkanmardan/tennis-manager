# Open source program readiness

Status checked 2026-09-20. These are preparation notes, not eligibility or acceptance claims. Provider rules may change; review the linked application before applying. The branch must be merged, CI observed, rights confirmed, and a verified release built before presenting this as a mature public project.

| Program | Current fit and likely requirements | Status / when to apply | Official entry point |
| --- | --- | --- | --- |
| JetBrains individual non-commercial use | Their current page says individual contributors to non-commercial OSS can use free IDEs without application. The established-project All Products Pack expects active development and broad developer impact. | Individual route: check personal terms now. Established-project program: **NOT READY YET**; build a track record. | [JetBrains OSS](https://www.jetbrains.com/community/opensource/) |
| BrowserStack Open Source | Open-source project and testing need; useful for Android device coverage after a repeatable build. Provider reviews applications. | Prepare after CI and a signed/testable APK; acceptance unknown. | [BrowserStack OSS](https://www.browserstack.com/open-source) |
| Snyk | A free developer plan is available and a maintainer program has an application. Use it to inspect pub dependencies; verify coverage of Dart before making claims. | Free plan can be tried now; special program approval unknown. | [Snyk plans](https://snyk.io/plans/) |
| Netlify Open Source | Requires an active non-commercial OSS project with an eligible license and Code of Conduct; intended for a project-related website. This Android repo has no docs site to host. | **NOT READY YET** until a useful public site exists. | [Netlify OSS](https://www.netlify.com/open-source/) |
| PVS-Studio Open Source | Free OSS licensing exists, but tool suitability for this Dart-first project has not been established. | **NOT READY YET**; validate language coverage first. | [PVS-Studio OSS](https://pvs-studio.com/en/order/open-source-license/) |
| Docker Sponsored OSS | Oriented to non-commercial projects using Docker images/Hub. This Android app publishes no container image. | **NOT APPLICABLE NOW**; revisit only if Docker distribution becomes real. | [Docker application](https://www.docker.com/community/open-source/application/) |
| GitHub OSS benefits / Sponsors | Public repo can use standard GitHub community/security features. Sponsors has separate account and country/tax eligibility and is not a quality badge. | Enable relevant repo settings now; sponsorship only if the owner wishes to seek funding and is eligible. | [GitHub Sponsors](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/about-github-sponsors-for-open-source-contributors) |

No program should be told there are external users, contributors, downloads, or CI success until independently verified. The most useful near-term application is a normal free security/developer plan; the high-trust OSS sponsorship routes should wait for verified releases and sustained maintenance.
